# proto/docs/ — working documents

Long-form working material that outgrows a worklog entry: investigation write-ups, playbooks, migration plans, specs handed off to work happening elsewhere.

- One subject per file, kebab-case filename.
- Open each doc with a date and a status line (`draft` / `active` / `superseded by <file>`). Outdated docs get marked, not deleted.
- Wire every doc into the record: link it from the WORKLOG entry that produced it, from `proto/STATE.md` when it drives the current stage, and from the `DEC-###` it informs.
- These documents are about *doing the work*. Knowledge that outlives the work belongs in the knowledge sources listed in `proto/connections.md`.
